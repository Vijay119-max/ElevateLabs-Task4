# Task 4 - Logistic Regression Classification

## Objective
Build a binary classifier using Logistic Regression.

## Dataset
Breast Cancer Wisconsin Dataset

## Steps Performed
- Loaded dataset
- Train-test split
- Standardized features
- Trained Logistic Regression model
- Evaluated using:
  - Confusion Matrix
  - Precision
  - Recall
  - ROC-AUC Score
- Performed threshold tuning

## Tools Used
- Python
- Pandas
- Scikit-Learn
- Matplotlib

## Results
The Logistic Regression model successfully classified malignant and benign tumors with high accuracy and ROC-AUC score.
